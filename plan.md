# Plan

I want to make a Bingo web app for my presentation. Guests will go to my URL on mobile and laptops e.g. bingo.joelbreit.com/session_id. It will be a React web app. They will provide their name and a shuffled board will be generated for them. Each square will represent a nugget of information that I will cover in the presentation. As I present, they will recognize that I've mentioned items and select them. When they select them, they will need to provide an answer to how well they knew the information beforehand. Basically they will answer that they did not know at all, partially knew, or were already familiar with the info. That will provide me with how much info I am providing, and allow them to stay engaged during the short presentation. Once they answer, they can mark off the box. They should be able to edit their answers. Users will be connected to the session via web socket so I should be able to have a live dashboard. When they get a row, they select which row to submit (if multiple) and can submit bingo, and the host can validate if all the  proposed topics have been covered.
